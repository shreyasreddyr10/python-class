About This Repository
This repository contains the Python programs completed for Assignment 1 of the Python Programming and Applications course.

The programs are organized unit-wise according to the assignment requirements and demonstrate fundamental concepts of Python programming, including data types, operators, functions, recursion, modules, packages, scope, mutability, and standard library usage.
